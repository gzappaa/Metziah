# קובץ התקנות.pdf

This PDF contains **Israel's Regulations for the Promotion of Competition in
the Food Industry (Price Transparency), 2014** — the law that mandates how
supermarket chains must publish their price/promo data (Reshumot 7442,
20 Nov 2014).

It defines the required XML file structure for large retailers: store lists,
product/price files, promotions files, and promo type codes — including field
names, lengths, and formats. This is the legal basis for the feed structure
this project parses; the structure is known in advance because it's
government-mandated, not reverse-engineered.
