# Decision 001: Use Google Geocoding API instead of GovMap

Date: 2026-08-04

## Context

The project needs to convert supermarket store addresses from the Laibcatalog XML feed into latitude and longitude coordinates.

Initially, GovMap autocomplete API was tested because it is free and Israel-specific.

## Experiment

Compared coordinates generated by GovMap against Google Geocoding API for 67 Mahsanei Hashuk stores.

Results:

- Compared: 67 stores
- Same within 100m: 29
- Different: 38
- Average distance: 13.3 km

Several stores had major mismatches:

Example:

Store:
- ID: 078
- Address: הלולים כפר עציון

GovMap:
- Wrong location
- Distance from Google: 220 km

Store:
- ID: 071
- Address: צה"ל 1 קרית מלאכי

GovMap:
- Wrong location
- Distance from Google: 123 km

## Decision

Use Google Geocoding API as the primary geocoding provider.

GovMap will not be used in the production pipeline.

## Reason

The cost is acceptable using Google Cloud credits, and Google produced more reliable results for supermarket locations.

## Consequences

Positive:
- More reliable store coordinates
- Less custom validation logic

Negative:
- Requires API key
- Has usage costs after credits/free tier

## Future considerations

Could keep GovMap as a secondary fallback or comparison source if needed.
